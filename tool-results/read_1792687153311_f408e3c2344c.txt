    29→    29→## Overview
    30→    30→
    31→    31→This project is a curated, searchable, and well-organized collection of the best free and high-quality resources for Web Development interview preparation. It covers every major area that appears in real interviews at companies of all sizes — from junior frontend roles to senior full-stack and system design positions.
    32→    32→
    33→    33→The application is fully bilingual. Users can switch between English and Persian at any time. The interface respects right-to-left layout for Persian, uses proper typography, and keeps navigation, search, and filtering intuitive in both languages.
    34→    34→
    35→    35→All resources listed in the source material have been included without omission. They are grouped by topic, annotated with short descriptions where useful, and presented in a clean, scannable format so candidates can quickly find the most relevant material for their current focus.
    36→    36→
    37→    37→---
    38→    38→
    39→    39→## Features
    40→    40→
    41→    41→- **Bilingual interface** — English and Persian with seamless language switching and correct RTL support for Persian.
    42→    42→- **Dark mode / Light mode** — System preference detection + manual toggle. Smooth transitions and carefully chosen contrast ratios in both themes.
    43→    43→- **High accessibility** — Semantic HTML, proper heading hierarchy, full keyboard navigation, focus management, ARIA where needed, and WCAG AA+ color contrast.
    44→    44→- **Clean yet attractive design** — Minimal visual noise, generous spacing, excellent typography hierarchy, subtle micro-interactions, and a calm color system that works equally well in light and dark mode.
    45→    45→- **Categorized resource library** — Every major interview topic has its own dedicated section with clear visual grouping.
    46→    46→- **Powerful search & filtering** — Instantly find resources by technology, difficulty level, content type (handbook, question bank, official docs, practice platform), or language.
    47→    47→- **Progress-friendly layout** — Built-in study roadmap, suggested order of topics, and space for future progress tracking.
    48→    48→- **Mobile-first responsive design** — Excellent experience on phones, tablets, and large desktop screens.
    49→    49→- **Fast and modern architecture** — Next.js App Router, Server Components where beneficial, and optimized client components for interactive parts.
    50→    50→- **Aceternity UI ready** — Designed from the start to accept beautiful free components from Aceternity UI without fighting the base design system.

    68→    68→### Why shadcn/ui + Aceternity UI?
    69→    69→
    70→    70→**shadcn/ui** provides accessible, high-quality primitives that you fully own. You get excellent defaults for buttons, cards, dialogs, tabs, forms, and navigation while keeping complete control over styling.
    71→    71→
    72→    72→**Aceternity UI** adds the delightful layer on top: animated backgrounds, spotlight cards, infinite moving cards, timelines, floating navbars, 3D card effects, and other free components that make a learning platform feel modern and engaging without adding complexity or heavy dependencies.
    73→    73→
    74→    74→Together they create a design that is simple, fast, accessible, and visually memorable.

    78→    78→## Aceternity UI Integration
    79→    79→
    80→    80→[Aceternity UI](https://ui.aceternity.com) is a collection of free, high-quality React and Next.js components built with Tailwind CSS and Framer Motion. It is the recommended way to elevate the visual quality of this project while staying true to the “simple yet attractive” design philosophy.
    81→    81→
    82→    82→### Why Aceternity UI fits this project
    83→    83→
    84→    84→- Completely free components
    85→    85→- Built for Next.js and React
    86→    86→- Uses the same Tailwind CSS foundation as shadcn/ui
    87→    87→- Excellent dark mode support
    88→    88→- Lightweight and performance-conscious when used selectively
    89→    89→- Perfect for creating memorable learning experiences without overwhelming the user
    90→    90→
    91→    91→### Recommended components for this project
    92→    92→
    93→    93→| Component                              | Suggested Use Case                                |
    94→    94→| -------------------------------------- | ------------------------------------------------- |
    95→    95→| Background Beams / Background Gradient | Hero section and category landing pages           |
    96→    96→| Spotlight Card / 3D Card Effect        | Individual resource cards                         |
    97→    97→| Infinite Moving Cards                  | Featured resources or “popular this week” section |
    98→    98→| Timeline                               | Study roadmap visualization                       |
    99→    99→| Floating Navbar / Dock                 | Main navigation                                   |
   100→   100→| Text Generate Effect / Typewriter      | Hero headline animation                           |
   101→   101→| Bento Grid                             | Overview of main topic categories                 |
   102→   102→| Hover Effect Cards                     | Technology or difficulty level filters            |
   103→   103→| Moving Border / Border Beam            | Call-to-action buttons and featured items         |
   104→   104→| Sticky Scroll / Reveal Animations      | Long content sections and roadmap steps           |
   105→   105→
   106→   106→### Integration guidelines
   107→   107→
   108→   108→1. Install only the components you actually use.
   109→   109→2. Keep the base design system (colors, spacing, typography) driven by shadcn/ui and Tailwind config.
   110→   110→3. Prefer subtle animations. Avoid motion that distracts from reading content.
   111→   111→4. Always test components in both light and dark mode and with reduced-motion preferences.
   112→   112→5. Place Aceternity components under `components/aceternity/` so they stay clearly separated from core shadcn primitives.
   113→   113→6. For Persian (RTL) layout, verify that animated elements and cards still align correctly.
   114→   114→
   115→   115→### Quick start with Aceternity UI
   116→   116→
   117→   117→```bash
   118→   118→# Most Aceternity components can be copied directly.
   119→   119→# Some require framer-motion:
   120→   120→pnpm add framer-motion
   121→   121→# or
   122→   122→npm install framer-motion
   123→   123→```
   124→   124→
   125→   125→Then visit [ui.aceternity.com](https://ui.aceternity.com), choose a free component, and follow the installation instructions shown on the component page. Most components are copy-paste friendly and work immediately with a standard Next.js + Tailwind setup.
