# DevReady

### پلتفرم دوزبانه آمادگی مصاحبه توسعه وب

پلتفرمی تولیدی و دوزبانه (انگلیسی / فارسی) برای آمادگی مصاحبه‌های توسعه وب — ساخته‌شده با **Next.js 16**، **React 19**، **TypeScript 5** و **Tailwind CSS 4** — شامل ۳۲ دسته، ۶۳۶+ منبع منتخب، تکرار فاصله‌دار، چالش‌های روزانه، حساب کاربری اختیاری با همگام‌سازی بین‌دستگاهی و الگوهای تاب‌آوری سازمانی.

## درباره

DevReady یک قالب نیست. هر کامپوننت، مسیر API و تصمیم طراحی از صفر ساخته شده تا فلسفه مهندسی خاصی را منعکس کند: **Type Safety به‌صورت پیش‌فرض، عملکرد به‌عنوان محدودیت، و دسترسی‌پذیری به‌عنوان متریک اصلی**.

این پلتفرم یک همراه مطالعه زنده است — شامل کاتالوگ منابع منتخب، نقشه‌راه‌های مطالعه، دسته مرور تکرار فاصله‌دار، چالش‌های روزانه با استریک، و سیستم حساب کاربری اختیاری با همگام‌سازی امن بین دستگاه‌ها. تمام محتوا کاملاً دوزبانه (انگلیسی / فارسی) با پشتیبانی صحیح RTL است.

## شروع سریع

### پیش‌نیازها

- **Node.js** ≥ 18 یا **Bun** ≥ 1.0

### نصب

```bash
git clone https://github.com/mohammadhossein-asadi/DevReady.git
cd DevReady
bun install
```

### دیتابیس

```bash
bun run db:push
```

### توسعه

```bash
bun run dev
```

مرورگر را به [http://localhost:3000](http://localhost:3000) باز کنید.

### بیلد تولید

```bash
bun run build
bun run start
```

## معماری

### همگام‌سازی چند-ذخیره

پنج ذخیره localStorage (library, daily, SRS, contribs, votes) از طریق موتور merge خالص با اعتبارسنجی ادغام می‌شوند. اسنپ‌شات ابری JSON مات است؛ تعارض‌ها با قوانین union/LWW حل می‌شوند.

### تکرار فاصله‌دار

زمان‌بند SM-2-lite با پیگیری ease/interval، باندهای تسلط (learning/familiar/confident/mastered) و re-queue با "Again".

### سیگنال‌های بلادرنگ

استریم SSE برای به‌روزرسانی آرا با اتصال خودکار مجدد و fallback به polling.
